# Regras de review do time

Projeto pequeno de demonstração (Node.js, sem dependências).

1. Nomes de função em snake_case (ex.: calcular_frete)
2. Toda função nova tem teste
3. Sem console.log no código
4. Mudou contrato de função? Liste quem chama, mesmo fora do diff

Pro resto (nomes ruins, números soltos, função grande), use a skill clean-code.
Ao revisar, confira o código contra o requisito da issue citada no PR.
